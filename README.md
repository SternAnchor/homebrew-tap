# Stern Anchor Homebrew Tap

Official Homebrew formulas for Stern Anchor tools.

## Install

Install a formula directly from this tap:

```bash
brew install SternAnchor/tap/blipwatch
```

Or tap first, then install:

```bash
brew tap SternAnchor/tap
brew install blipwatch
```

## Available Formulae

- `blipwatch`

## Support

For product issues, feature requests, and bug reports, use the primary project repository for each formula.
